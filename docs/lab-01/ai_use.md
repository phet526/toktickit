## Reflection

ผมว่าการให้ข้อมูลบริบทที่ชัดเจน เช่น การก๊อปปี้ Error Log จาก Terminal และโค้ดล่าสุดมาแปะ หรือเเคปรูปภาพ Error หรือ UI ที่พัง ช่วยให้ AI วิเคราะห์และแก้บั๊กได้แม่นยำขึ้นมาก (เช่น ตอนแก้ Type Error ใน React) แต่อย่างไรก็ตาม ผมก็ต้องคอยตรวจสอบและแก้ไขโค้ดที่ AI เขียนให้ด้วย เช่น ตอนที่ AI ให้โค้ดเทสฝั่ง Backend ที่เช็คชื่อหมวดหมู่ว่า "Account" ผมต้องเปลี่ยนเป็น "Account and Access" ด้วยตัวเองเพื่อให้ตรงกับข้อมูลที่ Seed ไว้ในฐานข้อมูลจริง เวลาใช้AIผมต้องคอยตรวจสอบและแก้ไขโค้ดที่ AI เขียนให้ด้วย ทำให้ได้เรียนรู้ไปด้วย
